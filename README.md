# Justin Ildefonso — Portfolio

One-page portfolio site for Justin Ildefonso (Web Developer · UX/UI · IT Support, Orlando, FL).
Plain HTML and CSS: no frameworks, no build step.

Intended to be published with GitHub Pages from the repo `Justinbecec1.github.io`,
at <https://justinbecec1.github.io>.

## Files
- `index.html`: page content (hero, about, projects, experience, skills, PC builds, contact)
- `style.css`: mobile-first responsive styles
- `resume.pdf`: current resume, linked from the page
- `preview-desktop.png` / `preview-mobile.png`: local screenshots (not needed on the live site)

## Publish
1. Create a public GitHub repo named `Justinbecec1.github.io`.
2. Upload `index.html`, `style.css`, `resume.pdf` and this README to the `main` branch.
3. In the repo, open **Settings → Pages** and set the source to `main` / root.
4. The site goes live at https://justinbecec1.github.io within a few minutes.

## Updating
- Add a project: copy one `<li class="card">` block in `index.html` and edit it.
- PC build photos: replace the "photos coming soon" HTML comment in the PC Builds section with `<img>` tags that have descriptive `alt` text.
